Nand2Tetris Projects
====================

Solutions for the projects in the book "The Elements of Computing Systems" by Noam Nisan and Shimon Schocken.

## 📚 Step-by-Step Learning Path

This repository follows a structured, step-by-step approach to building a modern computer from first principles. Each directory represents a step in the journey:

1. **[Gates](01_Gates)** - Boolean Logic and Basic Gates
2. **[ALU](02_ALU)** - Arithmetic Logic Unit
3. **[RAM](03_RAM)** - Memory and Sequential Logic
4. **[ASM](04_ASM)** - Assembly Language Programming
5. **[Computer](05_Computer)** - Complete Computer Architecture
6. **[Assembler](06_Assembler)** - Assembler Implementation

## 🚀 Getting Started

For detailed information about each step, including objectives, components, and learning outcomes, see **[STEPS.md](STEPS.md)**.

## 📖 About

These projects teach you how to build a complete computer system from NAND gates to running programs, following the curriculum from [nand2tetris.org](https://www.nand2tetris.org).
